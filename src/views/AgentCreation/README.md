# Agent 创作

现有设计保持不变，桌面入口已连接真实项目、会话和 Deep Agents / LangGraph 后台。实现范围与验证见 `docs/agent-integration.md`。

## 数据与执行边界

- `use-agent-workspace.ts` 只维护界面快照和未提交的编辑状态，通过 `src/agent/client.ts` 调用桌面宿主。
- 会话可独立存在；项目只整理会话，创建时不建书。后续可关联真实 bookId，项目名与书名独立。引用默认只读，作者明确修改时单独确定本轮写入目标。
- Agent 开书先保存可编辑草案，作者采用具体版本后建立作品；暂定名即可，不强制完整大纲。采用不会自动写正文。试写稿可以独立保存在会话中。
- 项目、会话、记忆、技能说明、成果、操作回执、检查点存放在统一 SQLite `desktop_records` 的不同命名空间中。
- 正式章节仍为平台 `chapter_contents`；Agent 修改在同一事务保留 `chapter_versions`、校验版本并保存操作回执。
- 运行状态来自原生后台，流式展示不等于正式写入成功。网页环境不启动本地后台，明确显示桌面端要求。
- 已移除生产入口的 demo 数据、定时器演示执行和虚假保存提示。
- Skills 说明可持久管理并由框架按需读取；第三方 Python 脚本执行尚未接入，不能将说明导入等同于脚本安装。

## 视觉约束

继续复用平台主题、背景图、`EwModal`、`ink-btn`、`ink-input`、`ink-select` 和 `inkConfirm`。对话与输入框沿用既有宽度和布局；正文按需展开；不另建公共控件皮肤。

Agent 挂载期间保持 `agent-workspace-active` 的桌面宽度适配，离开模块后恢复原页面规则。对话和引导选项保留各自历史状态，后续任务不重新激活旧消息。
