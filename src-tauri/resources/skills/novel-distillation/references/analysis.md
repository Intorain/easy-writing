# 从作品到可执行写法

## 确定材料与覆盖
以可读取的文本为依据，保留书籍或资料编号、章节编号、位置和读取时版本。用户限定某个阶段或场景时尊重范围；声称全书规律时才需要跨阶段、跨场景核对。根据文本长度和上下文分批阅读，不固定章数，不以读过目录、摘要或统计代替读过原文。

用户选择或明确限定局部范围时，可以交付对应范围的风格；不能自行缩小整本书任务，再靠范围声明将它当作完成。来源不足以支持的结论不补写。阶段报告记录哪些已读、哪些未读及下一步依据，便于中断后续做。工具返回截断时补读所需范围，结论仍绑定实际看过的内容。

## 书籍技法
围绕作者关心的问题观察：读者期待如何建立、人物主动选择怎样改变局面、信息与悬念怎样释放、回报怎样铺垫、场景怎样连接。把具体桥段转成可迁移的作用与条件，说明适用情形、做法和失效风险；分析报告可以描述来源事件，最终写作指引不搬人物、专有设定或原剧情顺序。

## 文风
观察叙述距离与态度、句段运动、对白和动作的交织、心理进入方式、感官与比喻的来源、信息进入场景的路径。维度是观察角度，不是每次必须填满的表格。关注一个做法怎样服务人物关系、阅读节奏和情绪，而不止形容“细腻、幽默、紧凑”。

分清主要声音、场景变化、角色专属口吻和题材词汇。统计只帮助找出值得精读的段落，不自动变成句长配额、禁词或文学质量评分。通过反例检查写法何时变化，避免把某个口癖、笑点或修辞放大到所有段落。

每条保留的写法应能帮助模型处理新场景：写出使用条件、具体动作，并在有助于理解时配原创示例。原创示例只演示表达，不重写原文的事件，不冒充引文。来源依据另外登记，区分原文观察、分析推断和跨书归纳。

## 同一作者的多部作品
先独立分析各书，再比较共同做法与差异。角色口吻、题材惯例和单本作品的叙事选择不能直接提升为作者全局规则。不同阶段或题材存在差异时分别保留适用条件，不强求平均成一套声音。多位作者的材料只能归纳为组合写法，不误标为某一作者的完整文风。

## 可复用的交付
技能正文集中写主动、明确、可执行的创作指引。原文位置、阅读范围、分析记录、例外和来源版本放参考文件；不打包整本原文。名称按实际提炼范围命名，不冒充原作者。作者已有设定和当次要求始终优先。

只有实际试写、审阅或读者选择才能作为对应效果记录。未试写就标明未验证，不把文件校验、模型自评或统计接近当作文风迁移成功。
